# Three.js Rotating Cubes Scene

A 3D scene built with Three.js that displays multiple rotating cubes arranged in a circular pattern.

## Project Structure

```
.
├── index.html          # Main HTML file
├── main.js             # Three.js scene setup and animation
├── package.json        # Project dependencies
└── README.md           # This file
```

## Technology Stack

- **Three.js** v0.160.0 - 3D graphics library
- **Vite** v5.0.0 - Build tool and dev server
- **JavaScript (ES6+)** - Programming language

## Expected Behavior

The application should display:
- A dark blue background
- 5 colored cubes (red, green, blue, yellow, magenta) arranged in a circle
- Each cube should rotate continuously
- Camera controls allowing orbit around the scene
- Proper lighting to see the cubes clearly

## Installation

```bash
npm install
```

## Running the Project

```bash
npm run dev
```

Then open your browser to the URL shown in the terminal (typically http://localhost:5173).

## Build for Production

```bash
npm run build
```
